# Wake word models (openWakeWord v0.5.1)

- `melspectrogram.onnx`, `embedding_model.onnx`: shared openWakeWord models (code Apache 2.0).
- `hey_jarvis_v0.1.onnx`: free **test word** until "Hey Cal" is trained. openWakeWord pre-trained models are licensed CC BY-NC-SA 4.0 (non-commercial).
- `word.json`: which word the planner listens for. Training "Hey Cal": `docs/hey-cal-training.md`.

Source: https://github.com/dscripka/openWakeWord/releases/tag/v0.5.1
